# Travel Destination Planner
project's main business idea is making accessing travelling destinations easier for users, without the need for extra hustle and unnecessary websurfing.

# Tech stack
Node.js	22.22.3
npm	10.9.8
Angular CLI	21.2.28
DB    
Architecture	Intel x86_64

# Mandatory Requirements

Admin Dashboard
• Login for admins
• Admin can fetch destination suggestions from a travel API (example: REST Countries or a tourism suggestions API)
• Admin adds/removes destinations to the internal DB
User Dashboard
• Login for users
• Users view all approved destinations
• Display details: country, capital, region, population, currency, flag/image
Nice to Have

•Destination search for users
• Users can mark a destination as “Want to Visit”

Bonus Features

• Admin can bulk-add destinations
• Pagination on destination list
